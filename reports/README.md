# Rapports du Desk Flow

Le scanner écrit ici un rapport Markdown par scan (`AAAA-MM-JJ-HHMM-flow.md`) et une copie
du dernier (`dernier-flow.md`) : régime de marché, opportunités retenues avec l'ordre calculé,
candidats écartés et pourquoi, flux Unusual Whales utilisés. Les rapports ne sont pas versionnés.
Les runs lancés depuis Claude (desk `flow-ia`) sont versionnés sous `reports/ia/`.
